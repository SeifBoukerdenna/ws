# market_workbench

A personal research workbench for creating, evaluating, and backtesting trading models on
event contracts, stocks/ETFs, and options. It never places orders: trades happen by hand, elsewhere.

Setup on macOS: `brew install uv just`, then `just setup`. Run `just` to list every command.

Rules, vocabulary, and layout: [AGENTS.md](AGENTS.md). Current plan: [ROADMAP.md](ROADMAP.md).
